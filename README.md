# 卡罗拉整车分解 · Corolla Exploded View

一个学汽车零件的网页：把一辆丰田卡罗拉（E210，北美版）炸开，点任意零件就能看懂
它叫什么、干什么、车上有几个、什么材料、怎么做出来的、怎么装上去的、大概多重多少钱、谁在造它。

**在线体验** → https://jyb635050-ai.github.io/corolla-3d/

纯静态零构建，three.js 自托管在 `vendor/`，**运行时不请求任何 CDN**，断网也能跑。

---

## 里面有什么

| | |
|---|---|
| 零件 | **434 条**，按丰田官方目录的四大部分 → 126 个官方图组组织 |
| 官方零件号 | 418 条带真实丰田零件号（如前制动盘 `43512-02370`） |
| 3D | 225 个零件建了独立可点网格，纯代码程序化建模 |
| 每条零件 | 中英名 · 作用 · 整车用量 · 材料 · 成型工艺 · 连接方式 · 重量 · 成本估算 · 供应商 · 装配关系 |
| 整车汇总 | 质量分布 · 材料构成 · 紧固件合计 · 成本构成 |
| 导出 | 一键导出 435 行 CSV（BOM），Excel 直开不乱码 |
| 语言 | 中英一键切换，英文模式全站零汉字 |

## 数据从哪来，以及不从哪来

- **零件号与官方零件名**：丰田 EPC 派生的公开零件目录。丰田真正的 BOM 和 TIS 是经销商授权资源、不公开，本项目**没有也不会**去碰。
- **供应商**：公开信息里该品类的主要厂商，逐条标 `confirmed` / `typical` / `guess`，只有能给出可打开来源的才标 confirmed。**不是丰田的官方配套名单。**
- **重量**：按品类的工程经验值，不是官方数据，也**不是**从 3D 几何算的——这套 3D 是示意模型不是数模。整车合计只用于量级自检。
- **成本**：参数化估算模型，`成本 = 重量 × (材料单价 + 工艺加工费率) + 紧固件数 × 0.6 元`，系数表在 `tools/enrich_parts.py` 里可查可改可复算。**不是丰田的采购价**，那个数公开渠道拿不到。
- **3D**：程序化示意模型，不是工程数模，尺寸不可用于任何工程用途。

## 本地跑

```bash
cd corolla-3d
python -m http.server 4399
# 打开 http://localhost:4399/index.html
```

ES module 不能用 `file://` 直接打开，必须起服务。

## 自检

```bash
uv run --no-project python tools/validate_data.py                      # 数据 35 条判定
uv run --no-project --with playwright python tools/verify.py           # 页面 27 条判定，自带静态服务
uv run --no-project --with playwright python tools/audit_weights.py    # 重量合理性审计
uv run --no-project python tools/audit_naming.py                       # id 与官方名一致性审计
```

`tools/enrich_parts.py` 负责按规则给全表补材料/工艺/连接/重量/成本，改完规则跑 `--write` 落盘。

## 已知的坑与限制

- 发动机半总成 92 kg、CVT 51 kg 等仍偏离真实值，装配树不完整时"子件之和"会失真
- 制动踏板零件号未查到（检索到的 47101-02510 属 2014–2019 款 E170/E180，47110-12390 是踏板带支架总成），留空未猜；机盖锁已补 53510-02770
- 前螺旋弹簧零件号 `48131-12J10` 号族存疑，标了 typical
- 3D 前脸端面敞口（车身曲面是单层壳，端头没封）、门下沿仍有穿帮。试过扇形封口，会折成 V 形折痕更糟，已撤回并在 car.js 里写明原因
- 整车质量合计只覆盖真车的约 37%——434 条是代表性选取，不是完整 BOM
